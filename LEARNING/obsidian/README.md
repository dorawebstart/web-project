# Obsidian vault — Навчання

Це Obsidian-сховище (vault). Нотатки зв'язані між собою через `[[wikilinks]]`, тому в **Graph view** (ліва панель → іконка графа, або `Ctrl/Cmd+G`) видно всю карту навчання.

## Як відкрити
1. Встанови Obsidian: https://obsidian.md
2. **Open folder as vault** → вибери цю папку `LEARNING/obsidian`.
3. Відкрий `Навчання` — це центральний вузол, від нього йдуть усі напрями.

Центр: [[Навчання]]
