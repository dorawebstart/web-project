Не курси, а готові відкриті інструменти — подивитись, як влаштовані, і за потреби використати.

- blackbird — OSINT: акаунти за нікнеймом (https://github.com/p1ngul1n0/blackbird)
- android-sms-gateway — Android-телефон як SMS-шлюз з API (https://github.com/capcom6/android-sms-gateway)
- voicetypr — голос у текст, локально (https://github.com/moinulmoin/voicetypr)
- openfaas/faas — serverless-функції на Kubernetes (https://github.com/openfaas/faas)
- websocketd — будь-яка CLI-програма → WebSocket-сервер (https://github.com/joewalnes/websocketd)
