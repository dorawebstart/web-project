# Дизайн-натхнення

Посилання на сайти, лендинги чи дизайн-галереї, які сподобались. Одне речення
чому — цього достатньо, щоб пізніше згадати, що саме тут цікаве.

_(поки порожньо — додавай сюди посилання, коли знайдеш)_

## Формат запису

```
- [Назва](посилання) — чому сподобалось / що саме цікаве (колір, анімація, типографіка, структура)
```
