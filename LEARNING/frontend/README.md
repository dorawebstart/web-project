# Веб-розробка: техніки, промти, дизайни

Живий довідник — на відміну від `courses.md` (що пройти), тут зберігаємо те,
чим користуємось у роботі: готові техніки з кодом, промти для AI-генерації
дизайну, посилання на натхнення. Поповнюй будь-коли, нічого не чекаючи.

## Файли

| Файл | Що туди йде |
|---|---|
| [`techniques.md`](techniques.md) | Конкретні CSS/JS-техніки з готовим кодом, які можна скопіювати й використати |
| [`ai-prompts.md`](ai-prompts.md) | Промти для генерації дизайну/верстки через AI — що спрацювало добре |
| [`design-inspiration.md`](design-inspiration.md) | Посилання на сайти з дизайнами, окремі лендинги, Dribbble/Awwwards тощо |

## Як користуватись

- Знайшов цікаву техніку у відео/статті → `techniques.md`, з кодом і коротким описом ефекту.
- Промт AI дав хороший результат → `ai-prompts.md`, зберігай сам промт і що вийшло.
- Побачив дизайн, який подобається → `design-inspiration.md`, просто посилання й одне речення чому сподобалось.

Нічого не вигадуй заздалегідь — додавай по факту, коли щось знаходиш.
