# Промти для AI-генерації дизайну/верстки

Промти, які дали хороший результат при генерації дизайну, компонентів чи
верстки через AI. Формат: сам промт + що саме вийшло + для чого придатний.

_(поки порожньо — додавай сюди промти, коли знайдеш або напишеш вдалий)_

## Формат запису

```
### Назва/призначення

Промт:
"..."

Результат: що вийшло, для чого підійшло.
Джерело/дата: звідки промт або коли сам написав.
```
