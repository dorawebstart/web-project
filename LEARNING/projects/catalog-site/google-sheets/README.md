# Варіант 1: наповнення через Google Таблицю

Власник редагує звичайну таблицю — сайт сам підтягує дані. Бекенд не потрібен.

## Крок 1. Створи таблицю

У Google Таблицях зроби аркуш з такими колонками в першому рядку (саме такі назви й порядок):

| name | category | price | description | image_url | available |
|---|---|---|---|---|---|
| Панорамна 2-кімнатна | Оренда | 30000 | Квартира біля парку | https://... | TRUE |
| Пиріг з вишнею | Випічка | 4600 | Солодкий пиріг | | FALSE |

- `price` — число без пробілів і валюти.
- `available` — `TRUE` або `FALSE` (великими літерами, це стандарт Google Таблиць для логічних значень).
- `image_url` — посилання на фото або порожньо.

## Крок 2. Відкрий доступ

**Файл → Поділитися → Доступ за посиланням → "Усі, хто має посилання" → Читач.**

Без цього кроку сайт не зможе прочитати таблицю.

## Крок 3. Знайди ID таблиці

ID — це частина посилання між `/d/` і наступним `/`:

```
https://docs.google.com/spreadsheets/d/1AbCDefGhIJkLmNoPQRstuVWxyz/edit
                                      ^^^^^^^^^^^^^^^^^^^^^^^^^^^^ це ID
```

## Крок 4. Встав ID на сайті

1. Відкрий `frontend/index.html` у браузері.
2. Натисни кнопку **"Google Таблиця"**.
3. Встав ID у поле і натисни **"Завантажити"**.

Сайт звертається до службового ендпоінту Google (`/gviz/tq?tqx=out:json`), який повертає вміст публічної таблиці у вигляді JSON — без API-ключа й без бекенду.

## Як це працює під капотом

Подивись `frontend/app.js`, функції `fetchGoogleSheet` і `parseGvizResponse`.
Google повертає не чистий JSON, а обгортку:

```js
google.visualization.Query.setResponse({ ...дані... });
```

Код витягує вміст дужок регуляркою і розбирає як звичайний JSON.

## Обмеження цього підходу

- Дані оновлюються з невеликою затримкою кешу Google (зазвичай кілька хвилин).
- Таблиця має бути публічною для читання — не клади туди чутливі дані (особисті номери телефонів, паролі).
- Для реального продакшену краще використовувати офіційний Google Sheets API з ключем, але для навчання вистачає й цього простого способу.
