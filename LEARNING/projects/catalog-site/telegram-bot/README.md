# Варіант 2: наповнення через Telegram-бота

Власник пише команди боту в Telegram — бот зберігає дані в SQLite — невеликий сервер
віддає ці дані сайту у форматі JSON.

```
Telegram (ти) → bot.py → products.db (SQLite) ← api_server.py → frontend (сайт)
```

## Крок 1. Онови venv та встанови залежності

Через кілька пакетів системи рекомендуємо окреме віртуальне середовище:

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Крок 2. Створи бота в Telegram

1. Відкрий Telegram, напиши **@BotFather**.
2. Команда `/newbot`, дай боту ім'я.
3. BotFather дасть токен на кшталт `123456:ABC-DEF...`. Збережи його.

## Крок 3. Запусти бота

```bash
export BOT_TOKEN="твій_токен_тут"    # Windows: set BOT_TOKEN=твій_токен_тут
python bot.py
```

Напиши своєму боту в Telegram `/start` — він має відповісти підказкою з командами.

## Команди бота

| Команда | Що робить |
|---|---|
| `/add Назва \| Категорія \| Ціна \| Опис \| URL_фото` | Додати позицію (URL_фото можна пропустити) |
| `/list` | Показати всі позиції з їхніми ID |
| `/remove ID` | Видалити позицію за ID |
| `/available ID так` | Зробити позицію доступною |
| `/available ID ні` | Зробити позицію недоступною |

Приклад:
```
/add Пиріг з вишнею | Випічка | 4600 | Смачний пиріг на листковому тісті |
```

## Крок 4. Запусти API-сервер (в іншому терміналі)

```bash
source venv/bin/activate
python api_server.py
```

Сервер підніметься на `http://localhost:5000`. Перевір у браузері:
`http://localhost:5000/api/products` — має показати JSON з усіма позиціями.

## Крок 5. Підключи сайт

1. Відкрий `frontend/index.html`.
2. Натисни кнопку **"Telegram-бот (API)"**.
3. Залиш `http://localhost:5000` або встав свою адресу.
4. Натисни **"Завантажити"**.

## Файли цього варіанту

- `db.py` — робота з SQLite (додати / видалити / список / змінити доступність).
- `bot.py` — сам Telegram-бот, обробляє команди.
- `api_server.py` — Flask-сервер, віддає `/api/products` як JSON для сайту.
- `products.db` — створюється автоматично при першому запуску (не комітиться в git).

## Чому два окремі процеси

Бот (`bot.py`) і сервер (`api_server.py`) — це два незалежні процеси, які працюють з
однією базою `products.db`. Так влаштовані реальні системи: один сервіс пише дані,
інший їх читає й віддає. Для навчання можна запускати обидва на своєму комп'ютері
одночасно (два термінали).
