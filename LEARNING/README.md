# Навчання

Папка для навчання: курси, план, графік і прогрес.

## Структура

| Файл / папка | Що там |
|---|---|
| `courses.md` | Список курсів, які хочу пройти (збираємо сюди все, що кидаю) |
| `courses/` | Нотатки та практика по кожному курсу (окрема папка на курс) |
| `projects/` | Навчальні проєкти "з нуля" (не прив'язані до конкретного курсу) |
| `python/` | База Python: нотатки, вправи, міні-проєкти |
| `frontend/` | Живий довідник: CSS/JS-техніки з кодом, AI-промти для дизайну, посилання на натхнення — поповнюється постійно |
| `plan.md` | План навчання (буде складено після збору всіх курсів) |
| `schedule.md` | Графік по тижнях (буде складено разом із планом) |
| `progress.md` | Що вчу зараз, дедлайни і що вже пройдено |

## Статус

Етап 1: збираю список того, що хочу вчити. План і графік поки не складаємо.
